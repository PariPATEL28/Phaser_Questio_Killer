# QuestionKiller

A 2D adventure game developed with JavaScript and Phaser.

## Description
During my Interface3 training, I worked on a game name QuestionKiller. I worked on the Game Design and Level Design, and then worked on the game logic using JavaScript and Phaser.
QuestionKiller combines 2D platforming with an interactive dialogue system.
The player can move, jump across platforms, interact with a character, and choose different dialogue options.Depending on the player's choice, Each choice can lead to a different conversation scene.

## Features

- 2D platform movement
- Player movement and jumping
- Collision detection
- Sprite animations
- Interactive characters
- Branching dialogue system
- Multiple dialogue choices
- Scene transitions
- Custom dialogue engine

## Technologies

- JavaScript
- Phaser
- HTML/CSS
