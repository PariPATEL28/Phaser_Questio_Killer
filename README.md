# QuestionKiller

A 2D adventure game developed with JavaScript and Phaser.

## Description

QuestionKiller combines 2D platforming with an interactive branching dialogue system.

The player can move, jump across platforms, interact with a character, and choose different dialogue options. Each choice can lead to a different conversation scene.

## Features

- 2D platform movement
- Player movement and jumping
- Collision detection
- Sprite animations
- Interactive characters
- Branching dialogue system
- Multiple dialogue choices
- Scene transitions
- Custom dialogue engine

## Technologies

- JavaScript
- Phaser
- HTML/CSS
- Webpack
